# 非同期記事要約と関連リンク取得の設計

## 目標

ブックマークを登録すると、そのリクエストでは保存だけを行い、すぐ記事画面へ移動する。AI要約は、本文取得に時間がかかってもブラウザーの画面を待たせずに処理する。情報が不足する場合は、元ページをChromiumで描画し、元ページから直接リンクされたページを深さ1まで補足取得する。Cloud Runサービスは1つだけとする。失敗した要約を自動実行せず、利用者がWebのボタンを押した場合にだけ再試行する。

## 非同期ジョブ

ブックマーク保存・記事の作成・初回要約ジョブの登録をFirestoreの1トランザクションで行う。初回だけ、利用量の上限に余裕があれば自動でキューに登録する。上限に達している場合もブックマークは保存し、要約を保留表示する。

各記事1件のFirestore `summary_jobs`ドキュメントに状態・段階・利用者・登録日時・実行権・期限・試行回数・最終エラーを保存する。Cloud RunのHTTPサーバーと同じプロセスで少数の常駐ワーカーを起動し、`queued`のみを取得して処理する。Firestoreのトランザクションで実行権を得るため、複数Cloud Runインスタンス間でも重複実行を抑える。

処理中は`fetching`、`rendering`、`following_links`、`summarizing`をFirestoreへ反映し、Webのポーリングで進捗を表示する。成功は`ready`、失敗は`failed`。失敗後にワーカーが自動キューへ戻す処理、定期リトライ、初回のCloud Run再起動時自動リトライは実装しない。リース期限切れは中断状態とし、本人が明示的に「要約を再試行」を押した場合だけ、所有権と利用上限を確認して再度`queued`にする。

SIGTERMでは新しいジョブ取得をやめる。処理中のジョブは保存されたリースを維持する。残り処理を再開しないままリースが切れた後、Webから再試行できる状態になる。処理結果の保存はジョブの実行権を照合して行い、古いワーカーが新しい実行を上書きしない。

## 記事取得

まず既存のSSRF対策を備えたHTTP取得機構で公開HTTP/HTTPSのHTMLを取得し、タイトル・本文・リンクを抽出する。本文が短い、取得できない、または初回要約が内容不足を示す場合はChromiumを使う。外部サイトへ向けてChromiumを直接ナビゲートしない。安全取得済みHTMLをローカルの空ページのDOMへ設定し、外部通信を遮断したままJavaScriptを短時間実行して、描画後の本文・リンクを読む。時間、HTML・DOM・出力テキストサイズを制限する。

利用できる文書リンクは元ページから得た直接リンクのみ。リンク先URLを同じ安全なHTTP取得機構で再検証し、公開アドレス、標準ポート、許可されたHTML、リダイレクト制限、サイズ上限、時間上限を各URLごとに適用する。子ページのHTMLからさらにたどらない。スコアで関連性を順位付けし、取得ページ数を最大3件に制限する。URL/ページの移動はFirestoreへ記録し、利用者が出所を確認できるようにする。

初回の根拠量が足りないときはGeminiに内容不足を構造化出力で判定させる。足りない場合、Chromiumで抽出した最大3件の関連ページを加えて一度だけ再要約する。本文中の命令は信頼せず、出典に書かれた情報だけをまとめる。最終結果は日本語1〜5項目でサーバー側検証する。

## Cloud Run

Webとワーカーは同じGoプロセス・同じCloud Runサービスで動かす。Cloud Runのinstance-based billing (`--no-cpu-throttling`)と1つ以上の最小インスタンスにより、HTTP応答後もワーカーのCPUを使えるようにする。CPUは2、メモリーは2 GiB、最大インスタンス数は3を初期値とし、同一サービス内のFirestore実行権で競合を制御する。`PORT`のHTTPサーバーとワーカーはSIGTERMを共有する。別Cloud Run Job/Service、Cloud Tasks、Pub/Subは追加しない。

## 画面とエラー

保存後すぐ記事詳細を表示。AI要約欄は待機中、本文取得中、ブラウザーで描画中、関連ページ確認中、要約中、完了、失敗、中断、利用上限を短い日本語で表示する。失敗・中断・利用上限に対しては、認証済み利用者に明示的な再試行ボタンを出す。自動再試行は行わない。初回登録の利用上限超過でも保存を成功させ、ボタンを出す。

## 検証

Firestore Emulatorで保存とジョブ登録の原子性、単一実行、明示再試行だけでキューに戻ること、状態・古い実行権拒否、利用上限、ジョブ再起動・中断を検証する。Chromiumの描画済み本文と1階層リンク制限を、外部アクセスしないローカルHTMLで検証する。PC/モバイルで進捗、失敗、再試行を確認する。Cloud Run本番のGoogle/Gemini認証情報がない範囲を報告する。
