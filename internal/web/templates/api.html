URLを登録する

トークンは x-shiori-api ヘッダー、またはURLの token パラメーターで送信できます。どちらか一方に1つだけ指定してください。

{{if .APIEndpoint}}

ヘッダーで送信

curl -X POST '{{.APIEndpoint}}' \
  -H 'x-shiori-api: {{if .IssuedToken}}{{.IssuedToken}}{{else}}YOUR_TOKEN{{end}}' \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/article","tags":["技術"]}'
{{if .IssuedToken}}{{end}}

URLパラメーターで送信

curl -X POST '{{.APIEndpoint}}?token={{if .IssuedToken}}{{.IssuedToken}}{{else}}YOUR_TOKEN{{end}}' \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/article","tags":["技術"]}'
{{if .IssuedToken}}{{end}} {{else}}

APIエンドポイントはデプロイ後に表示されます。

{{end}}

PUTでも同じ形式で登録できます。urlには「あとで読む: https://example.com/article」のように説明文を含められます。URLが複数ある場合は登録しません。同じURLは重複登録せず、コメント・タグを更新します。省略したコメント・タグは空になります。GETでは登録できません。

トークン付きURLは共有しないでください。外部ツールの履歴やログにも残さないようにしてください。

{{end}}
